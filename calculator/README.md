# かんたん電卓

外部ライブラリ・外部サービス・有料APIを使わない、HTML・CSS・JavaScriptの練習用アプリです。

## ファイル

- `index.html`：日本語の画面とボタンを定義します。
- `style.css`：色、大きなボタン、スマートフォンに収まる配置を定義します。
- `script.js`：数字の入力、四則演算、クリア、キーボード操作を処理します。

3ファイルは同じフォルダーに置いてください。インストールやビルドは不要です。

## Windowsでの起動

1. ZIPを展開します。
2. `calculator` フォルダーの `index.html` をダブルクリックします。
3. EdgeやChromeで電卓が開きます。必要なら右クリックして「プログラムから開く」で選択してください。

## Androidでの起動

ZIPを展開し、3ファイルを同じフォルダーに保存してください。ファイル管理アプリから `index.html` をChromeなどのブラウザで開きます。
端末のファイル管理アプリによっては、隣のCSS・JavaScriptファイルの読み込みが制限される場合があります。その場合は、次のローカル表示方法を利用してください。

### WindowsのPCからAndroidで表示する場合（Pythonがある場合）

1. PCとAndroidを同じWi-Fiに接続します。
2. PCで `calculator` フォルダーを開き、ターミナルで `python -m http.server 8000 --bind 0.0.0.0` を実行します。
3. PCの `ipconfig` でWi-FiのIPv4アドレスを確認します。
4. AndroidのChromeで `http://PCのIPv4アドレス:8000/` を開きます。
5. Windowsからファイアウォールの確認が出た場合は、信頼するプライベートネットワークでのみ許可します。終了時はPCのターミナルで Ctrl+C を押します。

これは端末間のローカル表示であり、外部サービスへの登録は不要です。

## 操作

例：`1` → `2` → `+` → `3` → `=` と押すと `15` と表示されます。

- 「クリア」で入力・計算途中の状態をすべて消します。
- 小数点も入力できます。数字の入力は12桁までです。
- キーボード：数字、`.`、`+`、`-`、`*`、`/`、`Enter` または `=`。`Escape` または `Delete` でクリアします。
- ボタンにフォーカスがある場合、Enterはそのボタンを押します。
- 演算記号を続けて押すと、最後に押した記号に切り替わります。
- 連続計算は入力順です。`2 + 3 × 4 =` は `20` になります。
- 計算結果は最大12桁の有効数字に丸めます。厳密な会計計算などを目的にしたものではありません。
- 0で割ると日本語でエラーを表示します。数字の入力またはクリアで再開できます。

## 学習の順番

`index.html` でボタンと表示欄を確認し、`style.css` で色やサイズを変え、最後に `script.js` の `calculate` 関数で四則演算の処理を確認すると理解しやすくなります。

## 動作確認

Linux上のChromiumで、12パターンの計算・キーボード操作、ボタンのクリック、クリア、ゼロ除算とその後の再入力を確認済みです。
幅1280px・360px・320pxで横にはみ出さないこと、ボタンが44px以上あること、JavaScriptエラーがないことも自動確認しました。
